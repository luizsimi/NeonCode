
# Site Portfolio NeonCode

Este é um portfolio web moderno e interativo desenvolvido com React, TypeScript e Tailwind CSS.

Projeto original disponível em: https://www.figma.com/design/NItOLofLU5byFFjGAP1ev0/Portfolio-Website

## 🚀 Como Executar

Instale as dependências:
```bash
npm install
```

Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

O aplicativo estará disponível em `http://localhost:3000`

## 🛠️ Tecnologias

- React 18
- TypeScript
- Tailwind CSS
- Motion (Framer Motion)
- Radix UI
- Vite

## 📦 Build para Produção

```bash
npm run build
```

Os arquivos otimizados serão gerados na pasta `build/`
